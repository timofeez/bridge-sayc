# Бридж SAYC — тренажёр (PWA)

Сайт, который устанавливается на телефон как приложение и работает офлайн. Хостинг бесплатный — GitHub Pages.

## Разделы
- **Теория** — торговля SAYC на русском (по официальной брошюре ACBL «SAYC System Booklet»), со ссылками на источники.
- **Тесты** — вопросы по теории.
- **Торговля** — тренажёры «Открытие», «Ответ партнёру» и полная торговля с роботом-партнёром (каждая заявка проверяется по SAYC, с объяснением).
- **Память** — запомнить руку, счёт вышедших карт, быстрый подсчёт HCP.
- **Шпаргалки** — флеш-карты (вероятности раскладов, запись, ключевые цифры SAYC) с интервальным повторением.

## Публикация на GitHub Pages
1. Заведите аккаунт на github.com и создайте публичный репозиторий, например `bridge-sayc`.
2. Загрузите в него все файлы: `index.html`, `app.js`, `engine.js`, `compete.js`, `play.js`, `gamify.js`, `hub.js`, `style.js`, `fx.js`, `history.js`, `theory2.js`, `dd.js`, `ddui.js`, `extra.js`, `tatarkin.js`, `lab.js`, `data.js`, `theory.js`, `manifest.json`, `sw.js`, `icon.svg` (кнопка **Add file → Upload files**).
3. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save.**
4. Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/bridge-sayc/`.

## Установка на телефон
Откройте адрес в Chrome (Android) → меню ⋮ → **Добавить на главный экран / Установить приложение**. На iPhone: Safari → «Поделиться» → «На экран Домой».

Нужен APK? Зайдите на https://www.pwabuilder.com, вставьте адрес сайта → Package for stores → Android — он соберёт APK из этого же сайта.

## Запуск локально
```bash
python -m http.server 8765
```
и откройте http://localhost:8765.

## Ограничения
- Два режима торговли: противники пасуют или торгуются («Полная игра»). Логика движка упрощённая: оцениваются первые заявки, глубокие ситуации — нет.
- После изменения файлов поменяйте `CACHE` в `sw.js`, чтобы телефоны подхватили новую версию.
